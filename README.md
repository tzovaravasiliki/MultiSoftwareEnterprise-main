# MultiSoftwareEnterprise — University / Training Project

A small collection of educational software artifacts including a **C# Azure Functions HTTP-trigger example**, a Visual Studio solution, training assets and a presentation.

## Repository contents
- `Function1.cs`: HTTP-triggered Azure Function returning a short welcome response.
- `MultiSoftwareBio.sln`: Visual Studio solution.
- `PhotosCodeHub/`: project images.
- `*.zip`: archived templates and code examples.
- `univators_project.ppt`: associated presentation.

## How to explore
Inspect the solution in Visual Studio with the relevant .NET and Azure Functions tooling. The code here is a small example; it is **not represented as a production-ready service**. Deployment needs its own Azure environment and configuration.

## Portfolio note
This repository is best categorized as **software engineering / cloud training** rather than biomedical research. Exact project ownership and team contributions should be confirmed before using it as a primary academic CV highlight.
